# Design System: iclaw Operator Console
**Project ID:** local-web-canister-console

## 1. Visual Theme & Atmosphere
「閉じた運用室」ではなく、「開かれた安全な作業卓」の空気を基調にする。全体は明るいニュートラル面の上に、ごく淡いアンバー、スレート、ストーンのぼかしを重ねて、安心感と見通しのよさをつくる。前景は半透明のガラスカードで統一し、情報密度は保ちながら圧迫感を減らす。強い色は常時使わず、状態表示と主要導線にだけ限定して使う。

## 2. Color Palette & Roles
- **Airy Canvas White (`#ffffff`)**: カードと浮遊面の基準色。画面全体に清潔感を与える主面として使う。
- **Soft Zinc Field (`#f4f4f5`)**: ページ背景の土台。真っ白ではなく、長時間見ても疲れにくい柔らかい明度を担う。
- **Mist Border Gray (`#e4e4e7`)**: 境界線と区切り。情報の整理には使うが、輪郭を強くしすぎない。
- **Calm Text Ink (`#18181b`)**: 見出しと主要本文。安全で落ち着いた印象を保ちながら、十分な可読性を確保する。
- **Slate Support (`#52525b`)**: 補助文、説明文、メタ情報。主役を邪魔せずに文脈を支える。
- **Trust Emerald (`#10b981`)**: success 系の固定色。正常、完了、問題なしを迷いなく伝える。
- **Guidance Amber (`#f59e0b`)**: pending や保留の固定色。注意喚起はするが、危険信号ほど強く見せない。
- **Protection Rose (`#f43f5e`)**: error 系の固定色。失敗、入力エラー、確認が必要な事象に限定して使う。
- **Pale Accent Amber (`#fef3c7`)**: 背景ブロブの一部。画面に人の温度を足し、無機質さを和らげる。
- **Clouded Slate Mist (`#e2e8f0`)**: 背景ブロブや淡い補助面。軽さと奥行きをつくるための空気色として使う。

## 3. Typography Rules
見出しはやや存在感のある display 系サンセリフを使い、親しみやすさと整理感を両立する。本文は読み疲れしにくい中庸なサンセリフで統一し、暗い運用画面のような硬さを避ける。小ラベルやステータスは `text-xs` 相当の小さめサイズに大文字と広めの字間を合わせ、情報の種類を静かに整理する。主要数値や重要タイトルは太さで差を付け、色ではなく階層で目立たせる。

## 4. Component Stylings
* **Buttons:** すべて pill 形状を基準にする。主要操作は白や淡色面の中でもすぐ識別できる、引き締まった単色面で構成する。副操作は白面と細い境界線で軽く保ち、危険操作だけ rose 系で分離する。
* **Cards/Containers:** 主要カードは大きめの角丸を持つガラス調の面で、`bg-white/80` 前後の半透明白と `backdrop-blur` を組み合わせる。影は強く落とさず、`shadow-sm` から `shadow-lg` までの柔らかい拡散影で浮遊感だけを加える。
* **Sidebar / Navigation:** サイドバー自体もカードとして扱い、一覧項目は小さなカード片で並べる。選択中は濃い文字と軽い境界強調で示し、暗い塗りつぶしには頼らない。
* **Inputs/Forms:** 入力欄は白面ベースに薄いグレー境界線を引き、読みやすさを優先する。フォーカスは淡いリングか境界色の変化で示し、過度な発光演出は使わない。
* **Badges / Status Pills:** 丸いカプセル形状で統一し、success=emerald、pending=amber、error=rose の3系統に固定する。状態色は常に淡い背景色とセットで使い、塗りつぶしの強さを抑える。
* **Toast / Floating Feedback:** 画面右下に白寄りの強いガラス面として重ねる。詳細は圧縮しつつ、必要な件数と状態だけを短く示す。

## 5. Layout Principles
全体は明るい背景の上に、背景ブロブ、ガラスカード、軽い影の3層で奥行きをつくる。レイアウトはモバイルでは縦積み、デスクトップではサイドバーと本文の2カラムを基本にする。余白は広げすぎず、一覧やダッシュボードでも情報が散らばらない密度を保つ。一覧やグリッドは段階フェードで静かに表示し、スケルトン時も同じ骨格を維持してレイアウトシフトを防ぐ。全体を通して、「見張る画面」ではなく「安心して操作できる管理画面」に見えることを優先する。
